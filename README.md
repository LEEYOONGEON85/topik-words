# topik-words — 일본어 화자를 위한 한국어 학습 단어 데이터

한국어 단어 · 일본어 뜻 · 한국어 예문 · 일본어 예문 번역 데이터입니다. 앱 「TOPIK 単語」(가칭)에서 쓰는 단어 데이터를 공개합니다.

## 바꾼 점 (원본과 다른 부분)
- 예문을 학습자용으로 다시 쓰거나 고쳤습니다 (단어가 주인공인 짧은 문장).
- 일본어 예문 번역(exampleJa)과 빈칸 위치(quizBlank)를 새로 만들었습니다.
- 일본어 뜻을 앱 표기 규칙에 맞게 다듬었습니다.
- 단어와 등급은 「한국어 학습용 어휘 목록」을 기준으로 골랐습니다.

이 저장소와 앱은 국립국어원, 국립국제교육원(TOPIK 주관 기관)과 관계가 없으며 그 기관들의 추천·보증을 받지 않았습니다.
